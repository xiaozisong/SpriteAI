# 登录功能需求与平台接入清单

> 版本：v0.1  
> 状态：开发落地稿  
> 范围：邮箱验证码、QQ 扫码、微信扫码

## 1. 登录方式

- QQ 邮箱验证码登录：仅允许 `qq.com`、`vip.qq.com`。
- Gmail 验证码登录：仅允许 `gmail.com`、`googlemail.com`。
- QQ 扫码登录：接入腾讯 QQ 互联网站应用。
- 微信扫码登录：接入微信开放平台网站应用。

## 2. 用户状态

| 状态 | 说明 |
|---|---|
| 未登录 | 可浏览公开页面，触发受保护行为时打开登录弹窗 |
| 验证码已发送 | 等待用户输入 6 位验证码 |
| 已登录 | 本地保存 access token 与用户信息 |
| 登录过期 | 清理本地状态并重新打开登录弹窗 |

## 3. 异常文案

| 场景 | 文案 |
|---|---|
| 邮箱为空 | 请输入邮箱 |
| 邮箱域名不支持 | 当前仅支持 QQ 邮箱和 Gmail |
| 验证码为空 | 请输入验证码 |
| 验证码错误 | 验证码错误或已过期 |
| 请求过快 | 请求过于频繁，请稍后再试 |
| QQ 登录失败 | QQ 登录失败，请重试 |
| 微信登录失败 | 微信登录失败，请重试 |
| 未勾选协议 | 请先阅读并同意用户协议和隐私政策 |

## 4. 平台接入准备

### 4.1 SMTP 邮箱服务

- 准备 SMTP Host、Port、User、Password。
- 生产环境建议使用企业邮箱或云邮件服务。
- 验证码有效期：10 分钟。
- 单邮箱发送频率：60 秒一次。

### 4.2 QQ 互联

- 创建网站应用。
- 配置回调地址：`{SERVER_PUBLIC_URL}/api/auth/oauth/qq/callback`。
- 获取 `QQ_CLIENT_ID`、`QQ_CLIENT_SECRET`。

### 4.3 微信开放平台

- 创建网站应用。
- 配置回调地址：`{SERVER_PUBLIC_URL}/api/auth/oauth/wechat/callback`。
- 获取 `WECHAT_CLIENT_ID`、`WECHAT_CLIENT_SECRET`。

## 5. 验收标准

- 用户可用 QQ 邮箱或 Gmail 收到验证码并完成登录。
- 用户可通过 QQ 扫码完成登录。
- 用户可通过微信扫码完成登录。
- 首次登录自动创建用户，二次登录命中同一用户。
- 登录成功后原有 `requireLogin` 拦截行为继续可用。
- 退出登录后本地 token 和用户信息被清理。
